# План реализации

## Этап 1. Основа проекта

- Создать структуру backend, frontend, desktop и docs.
- Настроить FastAPI.
- Настроить React/Vite.
- Подготовить Tauri shell.
- Добавить базовую русскую тему интерфейса.

## Этап 2. Регистрация и логин

- Модели пользователей и email-подтверждений.
- Hash паролей.
- JWT/session auth.
- SMTP через Mail.ru.
- Экраны регистрации, подтверждения и логина.

## Этап 3. Ключи и E2EE

- Генерация ключей на клиенте.
- Загрузка публичного ключа на сервер.
- Шифрование приватного ключа облачным паролем.
- Восстановление устройства.

## Этап 4. Друзья

- Поиск по username.
- Заявки в друзья.
- Invite-коды.
- Список друзей.
- Presence online/offline.

## Этап 5. Личные чаты

- Direct-чаты.
- WebSocket.
- Отправка и получение encrypted message.
- TTL сообщений 2 часа.

## Этап 6. Групповые чаты

- Создание групп.
- Роли участников.
- Групповой ключ.
- Ротация ключа при изменении состава.

## Этап 7. Медиа и голосовые

- Encrypted media upload.
- Voice recording.
- Voice playback.
- Отдельное хранение аватарок без шифрования.

## Этап 8. Лента

- Посты друзей.
- Комментарии.
- Реакции.
- Игровые статусы.

## Этап 9. Игровые интеграции

- Steam.
- Riot.
- Epic.
- EA.

## Этап 10. Desktop

- Tauri wrapper.
- Windows `.exe`.
- macOS build.
- Настройка backend URL.

## Этап 11. Деплой

- Windows Server guide.
- Linux Mint guide.
- Firewall, ports, reverse proxy.
- HTTPS through domain or tunnel.
