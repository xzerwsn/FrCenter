# Техническое задание FrCenter

## Назначение

FrCenter - desktop и web-приложение для общения с друзьями, групповых чатов, игровых статусов, постов и новостей с обязательным end-to-end шифрованием сообщений, вложений и голосовых сообщений.

## Язык и стиль

- Интерфейс: русский.
- Визуальный стиль: игровой dashboard в темно-бордовой палитре по референсу.
- В дальнейшем: поддержка смены тем.

## Платформы

- Web: обычный сайт в браузере.
- Desktop: Windows и macOS.
- Функции web и desktop-клиентов совпадают.

## Основные функции

- Регистрация по email и паролю.
- Подтверждение email.
- Логин.
- Облачный пароль для восстановления ключей устройства.
- Друзья по username и invite-коду.
- Личные и групповые чаты.
- E2EE для сообщений, вложений и голосовых сообщений.
- Аватарки без шифрования.
- Хранение сообщений на сервере не дольше 2 часов.
- Лента постов друзей.
- Комментарии и реакции.
- Игровые статусы, достижения и статистика.
- Интеграции Steam, Riot, Epic и EA отдельными модулями.

## Ограничения MVP

В первом рабочем прототипе игровые API можно заменить ручными игровыми статусами и подготовить архитектуру для интеграций. Steam и Riot являются первыми кандидатами для реального подключения.
